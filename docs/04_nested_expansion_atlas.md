# 04 — Atlas of nested letter expansion

> Generated by the ABJADCOMPUTER engine. Every value below is a sum of
> table look-ups and can be re-checked with pencil and paper.


A letter is a name as well as a sign. Replacing each letter by the letters that spell its name, recursively, turns a single value into a tree whose totals grow with depth. Level 0 is the bare sign; level 1 is its name; level 2 expands each letter of that name in turn.

## 1. The worked case: ا

```
L0  ا                         = 1
L1  ا -> ا ل ف                 = 1 + 30 + 80          = 111
L2  (ا)(ل)(ف)                  = 111 + 71 + 82        = 264
        ا -> الف = 1+30+80  = 111
        ل -> لام = 30+1+40 =  71
        ف -> فاء = 80+1+1  =  82
```

As a first-class expression: `ا(ا(الف)ل(لام)ف(فاا))` = **264**

The spec's own notation writes the last branch with the defective spelling فا rather than فاء. The evaluator honours whichever spelling is written:

```
apply ا@0  111 + 71 + 81 = 263
  apply ا@0.0  1 + 30 + 80 = 111
    leaf  ا@0.0.0  1
    leaf  ل@0.0.1  30
    leaf  ف@0.0.2  80
  apply ل@0.1  30 + 1 + 40 = 71
    leaf  ل@0.1.0  30
    leaf  ا@0.1.1  1
    leaf  م@0.1.2  40
  apply ف@0.2  80 + 1 = 81
    leaf  ف@0.2.0  80
    leaf  ا@0.2.1  1
```

`آ(آ(آلف)ل(لام)ف(فا))` = **263** (defective فا = 81)
`ا(ا(الف)ل(لام)ف(فاا))` = **264** (plene فاء = 82)

Both are reported because both are attested spellings; the engine never guesses which one a source intends.

## 3. Growth

Expansion is monotone but not uniform: a letter whose name is spelled with heavy letters climbs faster than its own weight suggests.

| fastest L0→L1 | ratio |  | slowest L0→L1 | ratio |
|---|---|---|---|---|
| ا (1→111) | 111.0 |  | ظ (900→902) | 1.00 |
| ج (3→53) | 17.7 |  | خ (600→602) | 1.00 |
| د (4→35) | 8.8 |  | ث (500→502) | 1.00 |
| ك (20→101) | 5.0 |  | ت (400→402) | 1.00 |
| ز (7→18) | 2.6 |  | ض (800→805) | 1.01 |

ا is the extreme case: weight 1 at L0, 111 at L1 — a factor of 111. The lightest sign carries the heaviest name, because its name ends in ف (80). This is why ا behaves as the engine's origin: it is the only node whose expansion changes its order of magnitude twice over.
